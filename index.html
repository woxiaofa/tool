什么是在线文本格式化工具箱？

文本格式化工具箱（Text Formatter Toolbox）是一个免费、开源、纯前端的在线文本处理工具， 支持 CSS 压缩与美化、HTML 压缩与格式化、Markdown 与 HTML 互转、段落整理、 中英文混排排版、标点全半角转换，以及 URL、Base64、JSON 的编解码与美化。 共 5 大类、30 多个一键操作，打开网页即可使用，无需注册、不限次数、不上传数据。

所有格式转换都由 JavaScript 在你的浏览器本地完成，输入的内容不会发送到任何服务器， 也不会写入 Cookie 或本地记录。断网后依然可以正常使用（已支持安装为离线应用）。整套工具是单个 HTML 文件， 零第三方依赖、零外部请求，你可以直接把它保存到本地硬盘当桌面软件用。

功能一览：5 大类文本处理工具

1. CSS 压缩 / 美化

把一行到底的样式表展开成可读格式，或压掉所有空白上线。

  • CSS 压缩（去注释、去空白、合并分号）
  • CSS 格式（多行，声明逐行缩进）
  • CSS 格式（单行，一条规则一行）
  • 还原原始内容，随时回退

2. HTML ↔ Markdown 互转

写文档和写网页之间来回切换，保留标题、列表、表格结构。

  • HTML → Markdown
  • Markdown → HTML
  • HTML 压缩 / HTML 美化
  • 代码块、表格、任务列表均支持

3. 段落整理

处理从 Word、PDF、网页复制过来的脏文本。

  • 去掉段落首行空格 / 行尾空格
  • 合并多余空行、删除所有空行
  • 段落智能拼接（按中英文自动判断是否补空格）
  • 按标点一句一行、去除重复行、行排序

4. 中英排版

解决中英文混排最常见的排印问题。

  • 中英文之间自动加空格
  • 英文标点后补空格
  • 中文标点 ⇄ 英文标点互转
  • 全角 ⇄ 半角转换
  • 英文大小写：全大写 / 全小写 / 首字母 / 句首 / 互换

5. 通用转换

开发和写作都常用的编码、转义处理。

  • JSON 美化 / 压缩
  • HTML 实体转义 / 反转义
  • URL 编码 / 解码
  • Base64 编码 / 解码（支持中文 UTF-8）

如何使用？三步完成文本格式化

  1. 粘贴文本把需要处理的 CSS / HTML / Markdown / 中文文本粘贴到左侧「输入」框，或点击「填入示例」先试一下效果。
  2. 选择操作在左侧分类里切换到对应工具，点击需要的按钮；也可以直接按 Ctrl + Enter 执行默认操作。
  3. 复制结果右侧「输出」框会实时显示结果，点「复制结果」带走，或用「结果回填输入框」继续做第二次处理。

小技巧：连续处理时把上一次的结果回填到输入框，就可以叠加多个动作，例如「Markdown → HTML」后再「HTML 压缩」。

常见问题（FAQ）

这个文本格式化工具是免费的吗？

是的，完全免费，且开源。项目以 MIT 协议发布，不限使用次数、不限制文本长度、不需要注册账号，也没有水印。

处理文本时，我的内容会被上传到服务器吗？

不会。这是一个纯前端工具，所有格式转换都在你的浏览器里用 JavaScript 完成，页面不发送任何网络请求。你可以断网使用，也可以使用浏览器的离线安装功能把它变成一个本地应用。

CSS 压缩会不会压缩出错、破坏样式？

压缩算法会先保护字符串、注释和 URL 再做空白处理，因此 content: "a b" 这类带空格的字符串不会被误删。重要文件建议压缩前先备份，页面内也提供了「还原原始内容」按钮，可一键回到压缩前的状态。

Markdown 转 HTML 支持哪些语法？

支持 ATX 与 Setext 标题、无序 / 有序 / 嵌套列表、任务列表、围栏代码块（可标注语言）、引用块、分隔线、表格及其对齐方式、图片、链接、自动链接、粗体、斜体、删除线和行内代码。输出的 HTML 可直接粘贴进文章编辑器。

中英文之间加空格，为什么要有这个规范？

在中英文混排时，汉字与拉丁字母之间缺少空隙会让文本显得拥挤、不易扫读。在汉字与英文、数字之间加一个半角空格，是中文排版界（如《中文排版需求》与各大公司文案规范）普遍推荐的写法。本工具会自动保护 URL、邮箱、代码块和 HTML 标签，不会在它们内部误加空格。

能把中文标点批量转成英文标点吗？

可以。在「中英排版」分类下有「中文标点 → 英文标点」和「英文标点 → 中文标点」两个按钮互转，覆盖逗号、句号、问号、感叹号、冒号、分号以及各类括号书名号。转换时会自动跳过小数点和千分位分隔符。

Base64 编码支持中文吗？

支持。编码前会先把文本按 UTF-8 转成字节再做 Base64，解码后再按 UTF-8 还原，因此中文不会出现乱码。解码时也会自动忽略换行和空格。

支持手机上使用吗？有快捷键吗？

支持，页面为响应式布局，手机浏览器上输入和输出会自动上下排列。桌面端快捷键为 Ctrl + Enter（macOS 为 ⌘ + Enter），可直接执行当前工具的第一个操作。

可以把这个工具下载到电脑上离线用吗？

可以。整个工具只有一个 HTML 文件，没有外部依赖，直接把 index.html 保存到本地双击打开即可使用；也可以在安装/添加到主屏幕后离线运行。
